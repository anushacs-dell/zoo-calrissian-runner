## [v0.4.0] - 2026-01-23

### Added

- Official PyPI publication — `zoo-calrissian-runner` is now installable via `pip install zoo-calrissian-runner`
- Dependency on `zoo-runner-common` for shared base runner functionality
- Dependency on `zoo-template-common` for reusable template utilities

### Changed

- Forked from [EOEPCA/zoo-calrissian-runner](https://github.com/EOEPCA/zoo-calrissian-runner) and moved under ZOO-Project organisation
- Major architectural refactoring: codebase modularised to eliminate duplicated logic across ZOO-Project runner packages
